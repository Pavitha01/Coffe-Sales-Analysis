# Coffee Sales Analysis

## Project Overview
This project analyzes coffee shop sales data using MySQL and Power BI. The goal is to understand sales performance, order activity, product performance, and sales trends.

## Tools Used
- **MySQL:** Data preparation and SQL-based analysis.
- **Power BI:** Interactive dashboard and visual reporting.
- **GitHub:** Project documentation and version control.

## Business Questions
The analysis explores:
- How sales change over time.
- How many orders and units are sold.
- Which products and product categories perform best.
- How sales vary by store.
- Which days and hours have higher sales.

## Project Files
- `powerbi/` — Power BI dashboard.
- `sql/` — MySQL analysis scripts.
- `docs/` — SQL query explanations and supporting documentation.
- `screenshots/` — Dashboard screenshots.

## Project Status
The Power BI report and MySQL query documentation have been uploaded. The SQL scripts, dashboard screenshots, and final findings will be added as the project is completed.
